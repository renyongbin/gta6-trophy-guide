An offline GTA VI (PS5) trophy guide and tracker: all 55 official trophies with a real guide in our own words and a cited source beside each one, a three-step platinum roadmap, category filters, a spoiler-free mode, and progress saved in your browser (localStorage) with export/import. No Rockstar logo, artwork, or game screenshots — an unofficial fan guide that works fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
